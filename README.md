# spoko

Instant, transparent sync of a developer's *work in progress* between their own machines —
files, git state (branch, commits, staged changes, stash), `.env`, Claude Code chats and
Docker volumes — end-to-end encrypted, with git-based three-way merge when machines diverge.

> Status: under active development (MVP). Design: [`docs/superpowers/specs/2026-10-28-spoko-design.md`](docs/superpowers/specs/2026-10-28-spoko-design.md),
